# Kitchen Appliance Portal

A client portal to track kitchen appliances for your new home project.

## Deploy to Vercel

### Option 1: One-Click Deploy (Easiest)
1. Go to [vercel.com](https://vercel.com)
2. Sign up/Login with GitHub, GitLab, or email
3. Click "Add New Project"
4. Choose "Import Third-Party Git Repository" or drag & drop this folder
5. Click "Deploy"

### Option 2: Via Vercel CLI
```bash
# Install Vercel CLI
npm install -g vercel

# Navigate to this folder
cd kitchen-portal

# Deploy
vercel

# Follow the prompts, then get your live URL!
```

### Option 3: GitHub + Vercel
1. Create a new GitHub repository
2. Push this folder to the repo
3. Connect the repo to Vercel
4. Auto-deploys on every push!

## Features
- Track appliances for Main Kitchen & ADU
- View ordered items from Frigidaire
- Direct links to Costco & Frigidaire product pages
- Select items and see running cost totals
- Mobile responsive design
